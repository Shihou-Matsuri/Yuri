# YuriEye：彩色立方体识别方案设计

> 目标：使用罗技 C922 网络摄像头，实时识别**同尺寸、不同颜色**的立方体，输出每个立方体的颜色与位置。
> 版本：v0.1（基线可运行）

---

已跑通并达到可用精度；剩余短板为**小目标/密集目标**与**蓝/紫**等样本偏少的颜色。

## 1. 目标与约束

| 项 | 说明 |
|---|---|
| 输入 | 罗技 C922 Pro Stream Webcam（1080p@30，78° 视场，自动对焦） |
| 目标物 | 30mm 同尺寸立方体，颜色：红/黄/绿/蓝/橙/紫；每色可多个同时出现 |
| 任务 | 检测画面中的立方体并分类颜色（同尺寸），输出每个立方体的颜色与 2D 位置 |
| 场景 | 较简单背景（桌面），多种颜色方块同时出现（每种颜色不止一个） |
| 机位 | 可固定可移动（移动后需重做颜色标定；3D/深度标定仅对固定机位有效） |
| 输出 | 颜色标签、2D 中心/包围框、像素面积；可扩展为深度/3D |
| 运行环境 | Windows + Python 3.12（仓库根 `lerobot_venv312`，OpenCV 4.12） |
| 算力 | RTX 5070 Ti 12GB（注意：`lerobot` 环境的 torch 为 CPU 版） |

**已探明的关键事实**
- 罗技 C922 = OpenCV 索引 **1**（索引 0 为笔记本 FHD Webcam，3/4 为虚拟摄像头）。
- DirectShow 设备顺序可用 `tools/list_cameras.py` 随时确认。
- `lerobot` 环境已含 OpenCV/numpy，基线方案零额外安装即可运行。

## 2. 方法选型

### 2.1 方案 A：经典 CV（基线，推荐先做）
管线：HSV 分色 → 形态学清理 → 轮廓提取 → 立方体几何校验 → 掩码覆盖率 → 去重 →（可选）同尺寸一致性过滤。

优点：无数据、无训练、CPU 实时、可解释、易调参。
缺点：对光照/背景敏感；颜色相近或接触/遮挡时需人工标定与调参。

### 2.2 方案 B：ML 目标检测（YOLO，增强）
- 每颜色一类（`red`/`green`/…），训练 YOLOv8n/v8s。
- 用基线的自动标注生成初始数据集（弱监督），人工抽检后训练。
- 优点：对杂乱背景/遮挡/光照更鲁棒，检测+分类一个模型搞定。
- 缺点：需要采集数据、标注、GPU 训练时间；本机需新建带 CUDA 12.8+ 的 torch 环境。

### 2.3 方案 C：混合（最终推荐）
1. **阶段 1**：经典 CV 基线上线（快、够用）。
2. **阶段 2**：用基线自动标注 → 训练 YOLO → 替换/并行检测。
3. **阶段 3（可选）**：相机内参标定 + 像素↔毫米换算 + 3D 位姿，供机械臂（YuriArm）抓取。

## 3. 系统设计

```
YuriEye/
├── configs/default.json        # 相机/几何/颜色参数（单一配置入口）
├── yurieye/
│   ├── camera.py               # 摄像头封装（DSHOW、分辨率、曝光/白平衡）
│   ├── color_utils.py          # HSV 掩码、取色采样、范围合并（含红色回绕处理）
│   ├── geometry.py             # 立方体轮廓几何校验
│   ├── detector.py             # 检测管线（HSV→轮廓→几何→覆盖→去重）
│   ├── visualize.py            # 画框/标签/掩码调试
│   ├── calib.py                # 相机内参标定（棋盘格）、去畸变、深度估算
│   └── config.py               # 配置加载
├── tools/
│   ├── list_cameras.py         # 枚举设备与索引
│   ├── live_detect.py          # 实时/单图检测演示
│   ├── calib_color.py          # 点击采样标定 HSV 范围
│   ├── calib_camera.py         # 棋盘格内参标定
│   └── capture_dataset.py      # 采集数据 + 自动标注（喂给 ML）
└── ml/                         # ML 路径（YOLO 训练）
```

### 数据流
`Camera.read()` → `undistort`（若已标定）→ `CubeDetector.detect()` → `Detection{label, confidence, bbox, center, area_px}` → 可视化 / JSON。

### 检测判据（立方体几何校验）
- 轮廓面积在 `[min_area_px, max_area_px]` 内；
- 轮廓近似凸（solidity 阈值，容忍阴影/出画凹陷），顶点数 4~8（立方体任意姿态轮廓）；
- 外接矩形宽高比在 `aspect_range` 内（默认 [0.3, 3.5]，兼容透视）；
- solidity（面积/凸包面积）与 fill_ratio（面积/最小外接矩形面积）达标；
- 轮廓内像素属于该颜色掩码的比例 ≥ `min_coverage`；
- 同物去重：中心距离小于 `dup_distance_px` 时保留置信度高者；
- 可选 `enforce_uniform_size`：同尺寸立方体面积应相近，剔除离群误检。

## 4. 相机与几何

- **颜色一致性**：固定机位 + 尽量固定光照；C922 支持手动曝光/白平衡，可在配置中关闭自动以稳定颜色，再运行 `calib_color.py` 标定。
- **内参标定**：打印棋盘格，运行 `tools/calib_camera.py`（≥8 张不同角度），保存 `configs/camera_calibration.json`，之后检测前先去畸变。
- **尺寸/深度**：已知立方体真实边长 `real_size_mm` 时，可由可见面像素面积估算距离：`距离 ≈ f * 真实边长 / 面宽像素`（正面视角较准）。2D 中心 + 距离即可支撑简单的抓取规划；完整 3D 需额外做手眼标定（属于 YuriArm 集成阶段）。

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 光照变化导致 HSV 漂移 | 固定曝光/白平衡；标定在真实光照下进行；ML 阶段提升鲁棒性 |
| 立方体互相接触/遮挡 | 阶段 1 记录为局限；阶段 2 用 YOLO/分水岭处理 |
| 背景与立方体颜色相近 | 提高 min_coverage/面积下限；或走 ML |
| 反光/高光 | 形态学开闭、覆盖率判据；必要时手动曝光压低 |
| 姿态极端（几乎看不到面） | 面积判据兜底；提示摆正机位 |

## 7. 待确认细节（不阻塞当前基线，请按需答复）

1. **立方体边长与颜色集合**：已确认 30mm、红/绿/蓝/橙/紫，后追加 黄（yellow，见 `configs/default.json`）。
2. **机位是否固定**：已确认可固定可移动。建议日常使用固定机位；移动后重跑 `calib_color.py`，内参/深度标定仅对固定机位有效。
3. **是否要对接 YuriArm 抓取**：默认暂只输出 2D + 估算距离；对接抓取需要相机到机械臂的坐标变换（手眼标定）。
4. **场景背景复杂度**：已确认较简单背景 + 每色多块同时出现。基线按多目标处理（每个颜色掩码输出多个轮廓）；同色方块互相接触时轮廓会合并，属已知局限，ML 阶段处理。

## 8. 全局兼容 / 技术债 / 回归（对应六项硬性要求）

### 8.1 全局兼容性
- YuriEye 位于 LeRobot 仓库根目录下，是独立子包（`yurieye`），与 `lerobot` 包无命名冲突。
- 未修改父仓库任何文件；`tools/*.py` 通过 `sys.path` 注入项目根目录，仅影响脚本自身进程。
- 运行环境沿用仓库根 venv（Python 3.12 + OpenCV 4.12 + numpy 2.x），代码使用 numpy 2.x 兼容写法。
- 潜在冲突点：若父仓库未来也定义 `Camera`/`Detection` 等通用名，需加命名空间前缀（已用 `yurieye.` 包隔离）。

### 8.2 技术债（已识别，最小化处理）
- 形态学核尺寸、HSV 默认范围属于启发式默认值：已收敛到配置/函数默认参数，不散落硬编码；换场景只需改配置。
- 经典 CV 对光照敏感，属于已知局限，由 ML 阶段兜底（不把 ML 塞进基线以保持简单）。
- `ml/train_yolo.py` 依赖未安装的 ultralytics：以清晰报错+文档引导，未安装前不影响基线运行。

### 8.3 回归风险
- 受影响模块：无（新建独立目录）。
- 建议回归范围：父仓库 `pip install -e ".[feetech]"`、`lerobot-find-port` 等命令不受影响；验证方式为编译检查全部 `.py` + 用 C922 实拍画面跑通基线检测。

### 8.4 文档
- README 提供快速开始；本文件为详细设计；`ml/README.md` 覆盖 ML 路径；`scripts/setup_env.md` 覆盖环境。
