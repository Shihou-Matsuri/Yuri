# Yuri 综合遥控台 · 需求 + GUI 风格规范

> 状态：**需求与风格定稿（U1，2026-09-04）** · 实现状态：🟢 课程项目已收尾
> 风格母版：MatsuriVoice `frontend/src/theme.ts` + `style.css`（浅色「花信」/ 深色「祭」双主题）
> 参考文件：`docs/gui-reference/`（主题源码 + 页面样板 + 移植说明）

## 1. 背景

Yuri 目前由多个终端入口分散控制：`leader_remote.py`（臂遥操作）、`car_remote.py` / `dual_remote.py`
（轮子）、`YuriChassis/camera_car_gui.py`（Tkinter 相机小车）、`YuriEye` 视觉工具。综合遥控台把它们
统一成一个可视化工作台，让操作者在一块面板里完成连接、状态观察、安全控制、手动干预与视觉反馈。

遥控台不做硬件控制层：继续通过 YuriArm TCP JSON 服务器 / 串口 / 现有模块接口下发指令，
不绕过 `SOUL.md` 的安全语义（看门狗、高频指令不回包、急停/恢复、单实例）。

## 2. 范围

### 2.1 本期（U2 MVP）

一个页面覆盖六个功能区：

| 区域 | 核心能力 |
|---|---|
| A. 连接与状态 | ESP32 WiFi TCP `192.168.4.1:8765` / USB `COM8@115200`；主动臂 COM7、YuriEye 摄像头可选；状态灯与最近遥测 |
| B. 机械臂 | 实时姿态读数；脚本化 `move_joints` / 单关节步进；夹爪开关；从 leader_remote 继承的 PID 单实例约束提示 |
| C. 小车 | 虚拟方向键 + 键位；连续 `car_drive`（≥10Hz 建议 20Hz）；反向开关；`car_stop` 轮急停 |
| D. 视觉 | 摄像头预览；YuriEye 检测结果叠加（bbox + 类别）；颜色标定入口 |
| E. 安全与日志 | 全局急停 / `resume`；心跳与 watchdog 状态；指令/错误时间线 |
| F. 有线相机小车 | USB `COM21` 下拉/刷新；键盘、按钮与 XInput；连续摇杆速度；独立急停与断开 |

### 2.2 非目标（一期不做）

- 替代 CLI：遥操作真机联调仍保留命令行与 pid 锁；
- 全自主抓取：只做感知显示与手动触发，`G1` 规划闭环单列里程碑；
- 视频流远端压缩/直播：只做本机工作台预览；
- 配置编辑全面可视化：首版用 JSON 配置，工作台只读展示关键值。

## 3. 产品与交互需求

### 3.1 工作台骨架

- 顶部导航：连接区 + 全局安全控制（急停永远可见）+ 主题切换（浅/深）+ 主状态。
- 六个区（A–F）用可折叠面板组织，互不遮挡；真机模式进入时先要求显式连接。
- 任何切换（主题、面板、页面）不得触发断开或停车的副作用。

### 3.2 语义与状态

- 展示「目标值」与「实际值」分离：例如小车速度目标 vs 遥测、关节目标 vs 读数。
- 指令来源（键盘 / 手柄 / 按钮 / 脚本 / leader 桥）必须显示在对应区。
- 状态灯语义：绿=就绪、琥珀=警告（降级/离线待重连）、红=急停或故障、灰=未连接。
- 急停/恢复按钮在每区重复出现，但共享同一个全局状态。

### 3.3 键盘操作

- 机械臂单动（非桥模式）：数字 1–6 选关节，`PageUp/PageDown` 步进，空格夹爪保持/停止；
- 小车：`W/S` 前后、`A/D` 横移、`Z/X` 旋转、空格停、`E` 轮急停、`Q` 刹停退出；
- 全局：`Esc` 复位全部、`F12` 全屏、方向键在虚拟车控制区焦点上才用于车速。

### 3.4 反馈与可操作性

- 所有写操作需展示最近一次指令与延迟；高频指令不回包，只显示发送心跳成功。
- 日志时间线可筛选（连接 / 指令 / 遥测 / 错误），保留最近 500 条，运行中不冻结。
- 断线后默认进入安全停止流程，禁止自动恢复运动；恢复需用户点 `resume` 并重连。

## 4. GUI 风格：MatsuriVoice「花信 / 祭」

### 4.1 主题令牌（值取自 MatsuriVoice，可在前端复刻）

| 令牌 | 花信（浅） | 祭（深） |
|---|---|---|
| `--bg` | `#F5F5FA` | `#1B1512` |
| `--card` | `#FFFFFF` | `#241C17` |
| `--header/sider` | `#FFFFFF` | `#1F1814` |
| `--text` | `#2A2A38` | `#F2E8D9` |
| `--text-2` | `#8A8A9E` | `#A89882` |
| `--border` | `#E8E8F0` | `rgba(217,164,65,0.20)` |
| `--primary` | `#7C6FE8`（紫罗兰茉莉） | `#E5484D`（朱红） |
| `--primary-soft` | `rgba(124,111,232,0.12)` | `rgba(229,72,77,0.16)` |
| `--gold` | `#D9A441` | `#D9A441` |
| `--shadow` | `0 4px 16px rgba(42,42,56,0.06)` | `0 4px 18px rgba(0,0,0,0.35)` |

字体：`"Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；圆角 8–12px；
浅色靠白色卡片 + 浅紫主色，深色靠暗棕底 + 朱红/金强调；禁止大面积纯蓝/纯绿背景。

### 4.2 组件风格

- 按钮：主按钮用 `--primary`，危险操作用朱红/红描边或实底；禁用态灰化，不透明闪烁。
- 输入/滑块：跟随卡片底色；聚焦环用 `--primary-soft`；单位与数值同格对齐。
- 面板：卡片底 + `--border` 描边，圆角 10–12px；标题栏小字标签 + 状态点，不套多层卡片。
- 表格：表头 `--card` 与 `--bg` 交替，行 hover 用 `--primary-soft`；超长值单行截断 + 悬浮全文。
- 状态点：8px 圆点，颜色按 3.2；loading 时在点内做细环形进度而非闪烁。
- 图标优先 Lucide 系风格线稿；每图标按钮有 tooltip 与键盘快捷键显示。

### 4.3 场景配色

| 语义 | 浅色 | 深色 |
|---|---|---|
| 就绪 | `#2F9E77` | `#4CC38A` |
| 警告 | `#D9A441` | `#E4B65B` |
| 危险/急停 | `#E5484D` | `#F05A5F` |
| 离线/禁用 | `#9C9CA8` | `#7A6F63` |
| 信息 | `#4C8DF5` | `#6FA6F7` |

### 4.4 布局与动效约束

- 顶栏固定高 56px，状态行高 32px，工作区最小宽 1200px（窄屏改横向滚动而非压缩按钮）。
- 页面不用背景插画；卡片层级最多两层；避免紫色渐变大面积铺底。
- 动效 ≤200ms（fade / translateY 2px / 阴影过渡），状态灯变化不带动画；
- 文本不随窗口缩放而缩放；按钮高度统一（36px），图标按钮 32×32px。

## 5. 技术建议（不锁定实现）

- 桌面壳参考 MatsuriVoice：pywebview / FastAPI 本机服务 + 单 exe；
- 前端参考 MatsuriVoice：Vue 3 + Vite + Naive UI + Pinia；主题按 4.1 令牌化；
- 传输层复用 `yuriarm` 命令协议与 `YuriChassis` transport；不要从零实现协议；
- 后端聚合进程可选：串口/网络只允许一个写者；真机首版仍逐模块独占并明示冲突。

## 6. 验收清单（U2）

- [ ] 浅/深主题可切换且全部控件即时生效，不重载页面；
- [ ] A–F 六个区均能在离线 mock 下演示，真机连接后同一布局可用；
- [ ] F 有线相机小车支持 COM 切换、键盘/手柄切换、连续速度、停止与急停；
- [ ] 急停按钮在任何滚动位置都可见；断线自动停车不自动恢复；
- [ ] 小车按钮按下发送连续 `car_drive`，松开立即 0 速；空格/E/Q 与 CLI 语义一致；
- [ ] 视觉区可显示单帧检测结果与 YuriEye JSON 输出；
- [ ] 日志筛选与最近 500 条记录可用；
- [ ] 新增文档同步更新 `README.md`、`ROADMAP.md`、`docs/HANDOVER_TO_CODEX.md`。
