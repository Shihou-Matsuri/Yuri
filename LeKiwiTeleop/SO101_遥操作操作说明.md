# SO-101 主动臂带动从动臂 — 操作说明（lerobot 0.6.1）

目标：**主动臂(leader, COM7)** 带动 **从动臂(follower, COM4)** 遥操作。轮子用你的独立代码控制，不经过 lerobot。

> 以下命令默认在 `LeKiwiTeleop/` 目录下执行（从仓库根先进 `cd LeKiwiTeleop`）。

## 0. 环境

```text
venv:   `lerobot_venv312/`（仓库根，Python 3.12.14, lerobot 0.6.1）
源码:   lerobot 0.6.1 editable（`pip show lerobot` 可查实际目录）
入口:   lerobot-teleoperate / lerobot-calibrate (在 venv Scripts 里)
端口:   主动臂 COM7 | 从动臂 COM4
```

> 装包提示：这台机器学校的 TLS 劫持会让 `uv` 下载失败，请用 venv 里的 `pip`。
> `..\lerobot_venv312\Scripts\python.exe -m pip install ...`

## 1. 硬件接线

```text
笔记本
 ├── USB口A → 主动臂控制板 (COM7, CH343)
 └── USB口B → 从动臂控制板 (COM4)
轮子: 走你原来的 COM5 / 独立代码, 与这里无关
```

确认两个口在线：

```bash
# 在 venv 里
C:/Users/21209/lerobot_venv312/Scripts/python.exe -c "import serial.tools.list_ports as lp; [print(p.device, p.description) for p in lp.comports()]"
```

## 2. 校准从动臂（首次连接需要做一次）

从动臂舵机需要校准范围。把从动臂摆到活动范围中间，运行：

```bash
..\lerobot_venv312\Scripts\lerobot-calibrate ^
  --robot.type=so101_follower --robot.port=COM4
```

按屏幕提示，依次把每个关节从一头转到另一头，回车记录。完成后会保存校准文件。**主动臂不需要校准。**

> 若已校准过，可跳过；重连报"Mismatch calibration"时才重跑。

## 3. 遥操作（主动臂带从动臂）

### 方式A：双击脚本
直接运行本目录的 `teleop_so101_start.bat`

### 方式B：手动命令行
```bash
..\lerobot_venv312\Scripts\lerobot-teleoperate ^
  --robot.type=so101_follower --robot.port=COM4 ^
  --teleop.type=so101_leader --teleop.port=COM7
```

运行后：**握着主动臂动，从动臂跟着动。** 停止按 Ctrl+C。

## 4. 参数速查

| 端 | 参数 | 值 |
|---|---|---|
| 从动臂 | `--robot.type` | `so101_follower` |
| 从动臂 | `--robot.port` | `COM4` |
| 主动臂 | `--teleop.type` | `so101_leader` |
| 主动臂 | `--teleop.port` | `COM7` |
| 帧率 | `--fps` | 60（默认） |

摄像头默认不开（`--robot.cameras` 空则无画面）；要看画面再配。

## 5. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| COM4/COM7 未检测到 | 对应板没插/没上电；先跑第1节的端口检查 |
| 舵机不动/抖动 | 从动臂没校准 → 先跑第2节 |
| 报 Mismatch calibration | 校准文件与舵机不一致 → 重跑校准 |
| uv 装包失败 njmu 证书 | 用 pip 不用 uv（见第0节） |

## 6. 轮子独立控制（不归 lerobot）

轮子仍用你原来的代码（走 COM5 那块板），与上面机械臂遥操作并行/分开运行，互不影响。
